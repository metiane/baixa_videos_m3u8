# baixa_videos_m3u8
# 📹 Video Downloader

Script em Python para extração e download automatizado de vídeo-aulas e arquivos de mídia a partir de URLs web, utilizando a biblioteca `yt-dlp` e `FFmpeg`.

> Projeto desenvolvido para a disciplina de Ciência da Computação.

---

## 🚀 Pré-requisitos

Antes de executar o projeto, certifique-se de ter o **Python 3.x** e o **FFmpeg** instalados no seu sistema operacional.

### Instalação das dependências no Arch Linux / CachyOS:

```fish
# Instalar o FFmpeg para fusão de áudio e vídeo
sudo pacman -S ffmpeg

# Instalar o pacote do yt-dlp
sudo pacman -S yt-dlp
